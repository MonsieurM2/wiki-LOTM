# PROTOTYPE — direction artistique (branche `prototype/art-direction`)

Ouvrir `PROTOTYPE-WIPE-ME-site.html`. Barre flottante en bas : ← / → ou flèches du clavier. URL : `?variant=A|B|C` et `?screen=chapter|entity|graph|search`.

Trois directions structurellement différentes, pas trois palettes :

- **A — Codex / Manuscript** : deux colonnes, lettrine, notes marginales (la preuve est une glose à côté de la ligne), hiérarchie en rubriques. Typographie : serif seule, corps 1,85 interligne, texte justifié. Couleur : charbon, or ancien, oxblood pour les filets. Mouvement : aucun.
- **B — Observatory / Instrument** : trois panneaux denses (corpus / lecture / inspecteur de preuve), grille et chiffres, graphe SVG, palette de commande. Typographie : system-ui pour l'interface, serif pour le texte only. Couleur : charbon, filets gris, or pour les étiquettes. Mouvement : aucun, volontairement « outil ».
- **C — Ritual / Immersive** : une seule colonne centrale, titre démesuré, presque pas de chrome, preuve révélée au survol, graphe en orbite. Typographie : serif à très grande échelle. Couleur : charbon, or, halos radiaux. Mouvement : un sigil qui respire (CSS `@keyframes`, 6 s).

Contenu réel : chapitre 1 *Crimson*, fiche Klein Moretti, graphe et recherche alimentés par le schéma décidé. Aucune donnée de production, aucune PR : branche jetable.
