# PROTOTYPE — direction artistique (branche `prototype/art-direction`)

Ouvrir `PROTOTYPE-WIPE-ME-site.html`. Barre flottante en bas : ← / → ou flèches du clavier. URL : `?variant=A|B|C` et `?screen=chapter|entity|graph|search`.

Le plan de design, sa revue critique et la critique après capture sont dans `DESIGN-PLAN.md`. Les captures finales sont dans `screenshots/`.

Polices auto-hébergées dans `fonts/` : Cormorant Garamond (titres, noms) et Spectral (corps, interface), toutes deux sous licence OFL.

Trois directions structurellement différentes, pas trois palettes :

- **A — Codex manuscript** : deux colonnes, lettrine, preuve en glose marginale bordée d'oxblood. Un seul geste fort : la glose.
- **B — Observatory instrument** : trois panneaux, grille technique sans arrondis, graphe SVG, palette de recherche. Aucune décoration.
- **C — Ritual immersive** : une colonne étroite, corps aligné à gauche, un unique sigil animé en ouverture, preuve révélée au survol.

Branche jetable, jamais mergée. Seule la décision retenue sera portée dans le site réel.
